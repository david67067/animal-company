📖 API Documentation

Base URL

POST /auth/login

Issue new tokens for a player/mod combination

curl -X POST /auth/login \ -H "Content-Type: application/json" \ -d '{"playerId":"player123","modId":"mod456"}'

POST /auth/refresh

Get a new access token using a refresh token

curl -X POST /auth/refresh \ -H "Content-Type: application/json" \ -d '{"refresh_token":"your_refresh_token"}'

GET /auth/verify

Verify and get info about current token

curl -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \ /auth/verify

POST /auth/logout

Revoke a refresh token

curl -X POST /auth/logout \ -H "Content-Type: application/json" \ -d '{"refresh_token":"your_refresh_token"}'

GET /mods

Get mod list for authenticated player

curl -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \ /mods
